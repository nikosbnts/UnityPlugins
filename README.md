# UnityPlugins

JUCE/CMake project for two audio plugins:

- VBAP
- Binaural

The project builds:

- Standalone applications
- VST3 plugins
- Unity native audio plugins `.dll`

---

## Project structure

```text
UnityPlugins/
├── CMakeLists.txt
├── README.md
├── .gitignore
├── Assets/
│   └── 0ele/
│       └── 48K_24bit_0ele/
│           └── HRIR wav files
├── Source/
│   ├── Common/
│   ├── VBAPPlugin/
│   └── BinauralPlugin/
└── build/
    └── generated automatically
```

The `build/` folder is generated by CMake and is not included in the repository.

---

## Source folders

### Common

```text
Source/Common/
```

Contains shared code used by the plugins.

### VBAP Plugin

```text
Source/VBAPPlugin/
```

Contains the source code for the VBAP plugin.

### Binaural Plugin

```text
Source/BinauralPlugin/
```

Contains the source code for the Binaural plugin, the HRIR loading logic, and the plugin editors.

---

## Assets

The HRIR files used by the Binaural plugin are located in:

```text
Assets/0ele/48K_24bit_0ele/
```

The `Assets/` folder is included in the repository because the Binaural plugin needs these files to run correctly.

During the build process, CMake copies the `Assets/` folder next to the Standalone executables.

## Requirements

Required tools:

- CMake 3.24 or newer
- Git
- Visual Studio with C++ build tools

In Visual Studio Installer, the following workload should be installed:

```text
Desktop development with C++
```

---

## Build with Visual Studio 2026 Insiders

Run the following commands from the root folder of the repository, where `CMakeLists.txt` is located:

```bat
cmake -S . -B build -G "Visual Studio 18 2026" -A x64
cmake --build build --config Release
```

For Debug build:

```bat
cmake --build build --config Debug
```

---

For Visual Studio 2022:

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

For Debug build:

## Clean build

To remove old generated files and rebuild from scratch:

```bat
rmdir /s /q build
cmake -S . -B build -G "Visual Studio 18 2026" -A x64
cmake --build build --config Release
```

## Unity plugins

The Unity plugin DLLs are copied to:

```text
build/UnityPlugins/
```

Main Unity plugin files:

```text
build/UnityPlugins/audioplugin_VBAP.dll
build/UnityPlugins/audioplugin_Binaural.dll
```

To use them in a Unity project, copy them into:

```text
UnityProject/
└── Assets/
    └── Plugins/
        ├── audioplugin_VBAP.dll
        └── audioplugin_Binaural.dll
```

The `Assets/` folder is also copied to:

```text
build/UnityPlugins/Assets/
```

If the Unity plugin needs access to the HRIR files, copy this folder as well into:

```text
UnityProject/Assets/Plugins/Assets/
```

---

## VST3 plugins

The VST3 plugins are copied to:

```text
build/VST3/
```

Example outputs:

```text
build/VST3/VBAP.vst3
build/VST3/BinauralTest.vst3
```

To use them in a DAW or VST host on Windows, copy them to:

```text
C:\Program Files\Common Files\VST3
```

---

## Standalone applications

Standalone executables are created inside the plugin artefact folders:

```text
build/VBAPPlugin_artefacts/
build/BinauralPlugin_artefacts/
build/BinauralParamsPlugin_artefacts/
```

Example Debug output:

```text
build/BinauralParamsPlugin_artefacts/Debug/Binaural.exe
```

Example Release output:

```text
build/BinauralParamsPlugin_artefacts/Release/Binaural.exe
```

For the Binaural standalone applications, the `Assets/` folder is copied next to the executable so that the HRIR files can be loaded automatically.

---

## Plugin targets

The project defines three main plugin targets.

### VBAPPlugin

Build formats:

- Standalone
- VST3
- Unity

### BinauralPlugin

Build formats:

- Standalone
- VST3
- Unity

### BinauralParamsPlugin

Build formats:

- Standalone only

This target is mainly used for testing the Binaural plugin through the parameter editor.

After building the project:

```text
Unity DLLs:
build/UnityPlugins/

VST3 plugins:
build/VST3/

Standalone applications:
build/*_artefacts/Release/
```

```text
build/UnityPlugins/
```

to:

```text
UnityProject/Assets/Plugins/
```
